# Polices des cartes cadeaux

Ces polices sont embarquées par le générateur PDF afin que le rendu ne dépende
pas des polices installées sur le serveur ou sur l'appareil du destinataire.

- `BodoniModa*.ttf` : Google Fonts, preset `ambassade`.
- `Montserrat-*.ttf` : projet Montserrat, preset `ambassade`.
- `Abel-Regular.ttf` : Google Fonts, preset `coquille`.

Les licences SIL Open Font License correspondantes sont conservées dans ce
dossier. Les noms de fichiers sont résolus uniquement depuis une liste interne :
aucun chemin ou fichier de police fourni par un client n'est accepté.
